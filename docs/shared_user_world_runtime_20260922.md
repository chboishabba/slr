# Shared User/World Runtime — Production Roadmap Addendum

Date: 2026-09-22
Status: production convergence addendum

## Why this addendum exists

The production runtime has advanced beyond the older evidence -> legal reasoning
-> product roadmap wording.  The recurrent acquisition machine, canonical
evidence, query-world adequacy machinery, generic LegalFollow and revision
safety now support a broader suite-level recurrence.

The production target is:

```text
consumer/question
  -> dependency slice / exact residual
  -> shared-world lookup
  -> reuse reviewed in-scope coordinates
  -> residual-sensitive producer for missing coordinates
  -> bounded acquisition
  -> explicit review/payment
  -> reviewed world delta
  -> affected-consumer recomputation
  -> repeat
```

Revision/replay uses the same dependency path for stale coordinates but is not
the ordinary discovery driver.

## Production consumers

The runtime must remain generic enough to serve:

- personal journal/timeline consumers;
- role-safe handoff consumers;
- legal matters/proof graphs;
- mission actual-vs-should;
- historical/public research;
- comparative worlds;
- report/export consumers.

Legal semantics are a specialization over the shared world, not the shared
world's ontology.
